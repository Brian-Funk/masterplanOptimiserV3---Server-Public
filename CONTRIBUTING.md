# Contributing

Contributions are accepted under `AGPL-3.0-only`. By submitting a contribution,
you certify that you created it or otherwise have the right to submit it under
that licence.

Keep pull requests focused and include tests for changed behaviour. Do not
submit credentials, personal data, private deployment material, internal agent
notes or copied code whose terms are unknown. Update dependency locks,
`THIRD-PARTY-NOTICES.md`, corresponding-source tests and public documentation
when the change affects them.

Use a truthful commit author identity. If another person contributed material,
record that contributor rather than attributing their work to somebody else.
